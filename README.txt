PORTFOLIO NURUL HIKMAH AZZAHRA
================================

CARA MENJALANKAN DI VISUAL STUDIO CODE
1. Ekstrak file ZIP ini.
2. Buka Visual Studio Code.
3. Pilih File > Open Folder, lalu pilih folder "portfolio_nurul".
4. Buka file index.html.
5. Cara paling mudah: klik kanan index.html > Open with Live Server.
   Jika belum ada, buka Extensions (Ctrl+Shift+X), cari "Live Server",
   lalu install ekstensi Live Server.
6. Klik "Go Live" di kanan bawah VS Code.

ALTERNATIF TANPA LIVE SERVER
- Buka folder hasil ekstrak melalui File Explorer.
- Klik dua kali file index.html. Website akan terbuka di browser.

BAGIAN YANG PERLU KAMU UBAH
- Foto profil: pada index.html, cari elemen .portrait-placeholder dan
  .mini-portrait. Ganti placeholder dengan tag:
  <img src="foto-saya.jpg" alt="Foto Nurul">
  Simpan foto kamu di folder yang sama dan sesuaikan CSS jika diperlukan.
- Email: cari emailkamu@example.com di index.html lalu ganti dengan email kamu.
- Instagram/LinkedIn/GitHub: ganti alamat tautan sosial media dengan akun kamu.
- Skill: ubah nama, keterangan, dan nilai --level di index.html sesuai kemampuan asli.
- Project: ganti contoh project dengan tugas atau karya yang benar-benar pernah dibuat.

CATATAN
Website ini memakai Google Fonts dari internet. Jika tidak ada koneksi internet,
website tetap berjalan tetapi menggunakan font pengganti.
Persentase skill dan proyek yang tampil adalah contoh yang bisa kamu sesuaikan.
